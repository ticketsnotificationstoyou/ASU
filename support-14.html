1. Getting started (one-time setup)

AppStoreUploader (ASU) talks to your App Store Connect account directly. To allow that, Apple requires an App Store Connect API key. You create it once and enter three values in ASU: the Key ID, the Issuer ID, and the private key file (.p8).

What you need

  • A Mac. Free on-device translation needs macOS 15 or later.
  • An Apple Developer account. Only the Account Holder or an Admin can create API keys.

Create the key in App Store Connect

  1. Sign in at appstoreconnect.apple.com.
  2. Open Users and Access → Integrations → App Store Connect API → Team Keys.
  3. Copy the Issuer ID shown at the top of the page (a long code like 11523f53-2a06-…).
  4. Click Generate API Key (or the + button). Give it any name, for example ASU, and choose the access role App Manager (or Admin).
  5. Copy the Key ID of the new key (10 characters).
  6. Click Download API Key to get the file AuthKey_XXXXXXXXXX.p8.
Important: Apple lets you download the .p8 file only once. Store it safely. If you lose it, revoke the key and create a new one.

Enter the three values in ASU

  1. Open ASU and go to Setup.
  2. Enter the Key ID and the Issuer ID.
  3. Load the private key in one of two ways: press Import .p8 File… and choose your AuthKey_XXXXXXXXXX.p8 file, or open the file in any text editor and paste its entire contents (including the BEGIN / END lines) into the private key field.
  4. Press Save ASC Credentials, then Validate Connection to check that everything works. Your keys are stored in the macOS Keychain on your Mac and are never sent to us.

You only do this once. If the connection works, your apps appear in the app list.

2. How to use ASU, step by step

  1. Choose your app and version. Pick the app, then the version that is editable (status Prepare for Submission).
  2. Fill in the main language. In Metadata, write the name, subtitle, keywords, description, promotional text, what’s new and your URLs (support, marketing, privacy policy) for your primary language.
  3. Tick the languages. In Languages, select the languages you want to add. Languages that are already translated are not selected again.
  4. Press Translate All. Everything is translated inside the app. Open any language in Metadata to review or edit the result.
  5. Upload. In Upload, you see only the new translations. Press Upload; each language is sent to App Store Connect, and its status is shown. Languages that were already in App Store Connect are not touched.
  6. Check in App Store Connect and submit your version as usual.

Name and subtitle are limited to 30 characters, keywords to 100, the description to 4000 characters. ASU shortens name and subtitle automatically when a translation is too long.

3. Free vs Pro

Free

  • On-device translation by Apple (macOS 15+).
  • About 20 major languages (Arabic, Chinese, Dutch, English, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Polish, Portuguese, Russian, Spanish, Thai, Turkish, Ukrainian, Vietnamese).
  • Language packs must be downloaded first (macOS → System Settings → General → Language & Region → Translation Languages). Plan for up to 20 GB of free disk space.
  • Works offline after the download. Nothing leaves your Mac.

Pro (monthly subscription)

  • Translation is unlocked instantly for 34 App Store languages, all in one click.
  • No language downloads and no extra disk space.
  • Includes languages that Apple’s on-device translation does not cover.
  • Pro is selected automatically once you subscribe.

Pro is an auto-renewing monthly subscription. The price is shown in the app before you subscribe. Payment is taken from your Apple ID; you can manage or cancel it any time in your Apple ID subscription settings. Use Restore Purchases in the app on a new Mac.

4. Note: app names in other languages

Apple requires an app name to be unique in each storefront. A name that is free in one country can already be taken by another app in another, for example in Japan. When that happens, App Store Connect rejects the name with a message such as “the app name you entered is already being used”. Because Apple rejects a whole language entry when any of its fields is invalid, a name or subtitle problem can block the other fields too.

What ASU does

  • It first tries your original name.
  • If Apple says the name is taken, ASU keeps your name and adds a number: YourApp 2, YourApp 3, … up to 10.
  • After the upload, an alert lists every language where the name was changed.
What you can do: if you prefer a different name in that language, open the language in App Store Connect (App Information → Localizable Information) and edit the name manually. You can also type your preferred name in ASU’s Metadata screen before uploading.

1. Начало работы (один раз)

AppStoreUploader (ASU) работает с вашим аккаунтом App Store Connect напрямую. Для этого Apple требует API-ключ App Store Connect. Его создают один раз и вводят в ASU три значения: Key ID, Issuer ID и файл приватного ключа (.p8).

Что понадобится

  • Mac. Бесплатному переводу на устройстве нужна macOS 15 или новее.
  • Аккаунт Apple Developer. Создавать API-ключи может только владелец аккаунта (Account Holder) или администратор (Admin).

Создайте ключ в App Store Connect

  1. Войдите на appstoreconnect.apple.com.
  2. Откройте Users and Access (Пользователи и доступ) → Integrations (Интеграции) → App Store Connect API → Team Keys.
  3. Скопируйте Issuer ID в верхней части страницы (длинный код вида 11523f53-2a06-…).
  4. Нажмите Generate API Key (или кнопку +). Придумайте имя, например ASU, и выберите роль App Manager (или Admin).
  5. Скопируйте Key ID нового ключа (10 символов).
  6. Нажмите Download API Key, чтобы получить файл AuthKey_XXXXXXXXXX.p8.
Важно: Apple позволяет скачать файл .p8 только один раз. Сохраните его в надёжном месте. Если потеряете, отзовите ключ и создайте новый.

Введите три значения в ASU

  1. Откройте ASU и перейдите в Setup.
  2. Введите Key ID и Issuer ID.
  3. Загрузите приватный ключ одним из двух способов: нажмите Import .p8 File… и выберите файл AuthKey_XXXXXXXXXX.p8, или откройте файл в любом текстовом редакторе и вставьте его полное содержимое (вместе со строками BEGIN / END) в поле приватного ключа.
  4. Нажмите Save ASC Credentials, затем Validate Connection, чтобы проверить соединение. Ключи хранятся в связке ключей macOS (Keychain) на вашем Mac и нам не передаются.

Это делается один раз. Если соединение работает, в списке появятся ваши приложения.

2. Как пользоваться ASU по шагам

  1. Выберите приложение и версию. Версия должна быть доступной для редактирования (статус Prepare for Submission).
  2. Заполните основной язык. В Metadata укажите название, подзаголовок, ключевые слова, описание, промо-текст, что нового и ссылки (поддержка, маркетинг, политика конфиденциальности) для основного языка.
  3. Отметьте языки. В Languages выберите языки, которые хотите добавить. Уже переведённые языки повторно не выбираются.
  4. Нажмите Translate All. Всё переводится прямо в приложении. Любой язык можно открыть в Metadata и проверить или поправить результат.
  5. Загрузите. В Upload видны только новые переводы. Нажмите Upload: каждый язык отправляется в App Store Connect, статус показывается рядом. Языки, которые уже были в App Store Connect, не затрагиваются.
  6. Проверьте в App Store Connect и отправьте версию на проверку как обычно.

Название и подзаголовок ограничены 30 символами, ключевые слова 100, описание 4000. Если перевод получился длиннее, ASU автоматически укорачивает название и подзаголовок.

3. Бесплатная версия и Pro

Бесплатно

  • Перевод на устройстве средствами Apple (macOS 15+).
  • Около 20 основных языков (арабский, китайский, нидерландский, английский, французский, немецкий, хинди, индонезийский, итальянский, японский, корейский, польский, португальский, русский, испанский, тайский, турецкий, украинский, вьетнамский).
  • Языковые пакеты нужно скачать заранее (Системные настройки → Основные → Язык и регион → Языки перевода). Заложите до 20 ГБ свободного места.
  • После загрузки работает офлайн. Ничего не покидает ваш Mac.

Pro (ежемесячная подписка)

  • Перевод сразу открывается для 34 языков App Store одним нажатием.
  • Никаких загрузок языков и дополнительного места на диске.
  • Включает языки, которых нет в переводе Apple на устройстве.
  • Pro выбирается автоматически после оформления подписки.

Pro это автопродлеваемая ежемесячная подписка. Цена показывается в приложении перед оформлением. Оплата списывается с вашего Apple ID; управлять подпиской и отменять её можно в любой момент в настройках подписок Apple ID. На новом Mac используйте Restore Purchases в приложении.

4. Важно: названия приложения в других языках

Apple требует, чтобы название приложения было уникальным в каждом сторе. Имя, свободное в одной стране, может оказаться занятым другим приложением в другой, например в Японии. Тогда App Store Connect отклоняет имя с сообщением вроде «the app name you entered is already being used». Поскольку Apple отклоняет всю запись языка целиком, если любое её поле невалидно, проблема с именем или подзаголовком может заблокировать и остальные поля.

Что делает ASU

  • Сначала пробует ваше исходное имя.
  • Если Apple отвечает, что имя занято, ASU сохраняет ваше имя и добавляет цифру: YourApp 2, YourApp 3, … до 10.
  • После загрузки появляется уведомление со списком языков, где имя было изменено.
Что можно сделать: если вам нужно другое имя в этом языке, откройте язык в App Store Connect (App Information → Localizable Information) и измените название вручную. Можно также заранее вписать нужное имя на экране Metadata в ASU.
